# AlphaFeed news bot — настройка с iPhone (бесплатно)

Всё делается через Safari или приложение GitHub на iPhone. Сервер не нужен —
за вас работает GitHub Actions (бесплатно: у публичных репозиториев лимитов
практически нет, у приватных — 2000 минут в месяц, боту хватит с запасом).

## Шаг 0. Замените засвеченные токены

Если ещё не сделали:
- Telegram: @BotFather → `/mybots` → @Bistrobobot → API Token → Revoke → получить новый
- OpenAI ключ этому боту не нужен вообще — можно просто удалить его на platform.openai.com/api-keys

## Шаг 1. Узнайте chat_id вашего канала/чата

1. Создайте Telegram-канал (если ещё нет) и добавьте туда @Bistrobobot как администратора.
2. Отправьте в канал любое сообщение.
3. В Safari откройте:
   `https://api.telegram.org/bot<ВАШ_НОВЫЙ_ТОКЕН>/getUpdates`
4. В ответе (JSON) найдите `"chat":{"id":-100XXXXXXXXXX, ...}` — это и есть chat_id
   (для каналов он отрицательный, начинается на -100).

## Шаг 2. Создайте репозиторий на GitHub

1. Установите приложение GitHub из App Store (или работайте через Safari, github.com).
2. Зарегистрируйтесь / войдите.
3. New repository → назовите, например, `alphafeed-bot` → Create.
4. Через "Add file" → "Upload files" загрузите ВСЕ файлы из этого пакета,
   сохраняя структуру папок (важно: `.github/workflows/news.yml` должен
   остаться именно по этому пути, не в корне).

   На iPhone это удобнее сделать через Safari (десктопная версия сайта):
   в правом нижнем углу Safari → "Site settings" → "Request Desktop Website",
   так интерфейс загрузки файлов будет удобнее.

## Шаг 3. Добавьте секреты

В репозитории: Settings → Secrets and variables → Actions → New repository secret.

Добавьте:
- `TELEGRAM_BOT_TOKEN` — новый токен бота
- `TELEGRAM_CHAT_ID` — то, что нашли в Шаге 1
- `GEMINI_API_KEY` — необязательно. Если хотите живой стиль постов через
  бесплатный Google Gemini, получите ключ на aistudio.google.com/apikey
  (бесплатный тир — без карты, просто аккаунт Google) и добавьте сюда.
  Без этого ключа бот всё равно работает, просто пост будет более
  шаблонным (заголовок + краткое содержание + ссылка + хэштеги).

## Шаг 4. Включите Actions и проверьте вручную

1. Вкладка "Actions" в репозитории → разрешите workflows, если спросит.
2. Слева выберите "AlphaFeed news bot" → справа кнопка "Run workflow" → Run.
3. Через минуту откройте свой Telegram-канал — должны появиться посты
   по свежим новостям (младше 3 часов на момент запуска).

Дальше бот сам запускается каждые 2 часа (расписание в
`.github/workflows/news.yml`, строка `cron: "0 */2 * * *"`) —
ничего делать не нужно.

## Настройка под себя

- **Частота запуска**: поменяйте `cron: "0 */2 * * *"` на `"0 */1 * * *"` (раз в час) и т.п.
- **Окно свежести**: `HOURS_WINDOW: "3"` в news.yml — можно 1, 2, 6 часов.
- **Источники**: список `FEEDS` в `fetch_and_post.py` — добавляйте любые RSS-ссылки.
- **Хэштеги/ключевые слова**: словарь `HASHTAG_MAP` в том же файле.

## Важно понимать

- Это работает без вашего участия и без открытого iPhone/компьютера —
  GitHub Actions выполняется в облаке GitHub.
- Полностью бесплатно при разумной частоте (каждые 1–2 часа).
- Бот не проверяет факты и не "думает" — это automation по RSS, полный
  аналог того, что мы делали руками в чате, просто без ручного запроса.
- Если каких-то источников (например, The Block) RSS отвалится или
  сменит адрес — просто замените ссылку в списке FEEDS.
